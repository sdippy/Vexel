# Инструкции для GitHub Copilot

## Генерация коммитов

Когда пользователь запрашивает генерацию сообщения коммита:

1. **Язык**: Всегда пишите коммиты **на русском языке**
2. **Формат**: Используйте структурированный формат:

   ```
   <тип>(<область>): <описание>

   <детальное объяснение>
   ```

3. **Типы коммитов** (в прошедшем времени):
   - `feat` → `добавлено` (новая функция)
   - `fix` → `исправлено` (исправление ошибки)
   - `refactor` → `оптимизировано` (переструктурирование кода)
   - `style` → `стилизовано` (форматирование, нет изменений логики)
   - `perf` → `оптимизирована производительность` (улучшение производительности)
   - `test` → `добавлены тесты` (добавление/обновление тестов)
   - `docs` → `обновлена документация` (обновление документации)
   - `chore` → `обновлены зависимости` (обновление зависимостей и т.д.)

4. **Примеры** (в прошедшем времени):
   - ✅ `добавлено(auth): добавлена двухфакторная аутентификация`
   - ✅ `исправлено(dashboard): исправлена ошибка при загрузке графика`
   - ✅ `оптимизировано(store): оптимизированы селекторы Redux`

5. **Правила**:
   - Тип комита должен быть написан в изъявительном наклонении и в прошлом времени (например, "добавлено", "исправлено", "оптимизировано").
   - Первая строка не более 50 символов
   - Начинайте с глагола в Изъявительное наклонении (Добавлено, добавлены, исправлено, оптимизировано и т.д.)
   - Без точки в конце первой строки
   - Будьте конкретны и информативны
